# Komponentler

**Bu klasör ne?** Her komponentin bir klasörü olacak. İçinde komponentin **kimlik kartı** olan `spec.md` dosyası durur.

```
components/
└── button/
    └── spec.md   ← varyantlar, state'ler, kullandığı token'lar, Figma linki
```

**Neden önemli?** Dokümantasyon, Storybook ve video bu dosyadan üretilir. Bir komponent Figma'da değişince önce bu dosya güncellenir, gerisi ondan türer.

**Durum:** Henüz boş. `spec.md` formatı Faz 2'de doküman kurallarıyla birlikte belirlenecek ([ROADMAP.md](../ROADMAP.md)).
