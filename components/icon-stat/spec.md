# Icon Stat

A small count with an icon, e.g. the number of countries. Vertical stacks the icon above the value; Horizontal puts them in a row. Swap the icon from the panel.

## Variants

| Axis | Values | Default |
|---|---|---|
| Layout | Vertical, Horizontal | Vertical |

## Properties

| Property | Type | Default |
|---|---|---|
| Layout | Variant | Vertical |
| Icon | Instance swap | Globe |
| Value | Text | 3 |
