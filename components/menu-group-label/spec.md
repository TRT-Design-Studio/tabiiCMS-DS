# Menu Group Label

Heading for a group of Menu items, e.g. "3 selected" or "Shows · 12".

## Variants

None.

## Properties

| Property | Type | Default |
|---|---|---|
| Label | Text | Group |

## Sizes

| Height | Padding | Text |
|---|---|---|
| 28 | `Spacing/2` (8) top and sides, `Spacing/1` (4) bottom | `text-xs/medium`, `text/tertiary` |

Width 240, fills the menu.

## States

None.

## Used in

Menu (Items slot).
