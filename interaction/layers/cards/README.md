# Cards code layer

**Bu klasör ne?** Figma'daki "🗂 Cards" sayfasının Interaction frame'ine konan dosya. `node interaction/build.mjs` ile üretilir, elle düzenlenmez.

**Nasıl kullanılır?** `index.html` dosyasının içeriğini Figma'daki code layer'a yapıştır. Adımlar: [interaction/README.md](../../README.md).
