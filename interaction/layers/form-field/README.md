# Form Field code layer

**Bu klasör ne?** Figma'daki "↪︎ Form Field" sayfasının Interaction frame'ine konan dosya. `node interaction/build.mjs` ile üretilir, elle düzenlenmez.

**Nasıl kullanılır?** `index.html` dosyasının içeriğini Figma'daki code layer'a yapıştır. Adımlar: [interaction/README.md](../../README.md).

Komponentler: tooltip, label, input, menu-item, menu-group-label, menu-separator, badge-count, button, menu, select, textarea, field-message, form-field.
