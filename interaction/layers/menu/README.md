# Menu code layer

**Bu klasör ne?** Figma'daki "📋 Menu" sayfasının Interaction frame'ine konan dosya. `node interaction/build.mjs` ile üretilir, elle düzenlenmez.

**Nasıl kullanılır?** `index.html` dosyasının içeriğini Figma'daki code layer'a yapıştır. Adımlar: [interaction/README.md](../../README.md).

Komponentler: menu-item, menu-group-label, menu-separator, badge-count, button, menu, icon-button.
