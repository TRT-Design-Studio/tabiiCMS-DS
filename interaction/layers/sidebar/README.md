# Sidebar code layer

**Bu klasör ne?** Figma'daki "↪︎ Sidebar" sayfasının Interaction frame'ine konan dosya. `node interaction/build.mjs` ile üretilir, elle düzenlenmez.

**İstisna:** Bu sayfa spec'ten üretilmez. `interaction/reference/sidebar/` klasöründeki elle yazılmış kod (index.html, style.css, app.js) tek dosyada birleştirilir. İçinde farklı animasyon setleri (Ease out, Cascade, Scrub) gösterilir.

**Nasıl kullanılır?** `index.html` dosyasının içeriğini Figma'daki code layer'a yapıştır. Adımlar: [interaction/README.md](../../README.md).
