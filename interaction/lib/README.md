# Okuyucular

**Bu klasör ne?** Build script'inin yardımcıları.

- `spec.mjs`: `components/<isim>/spec.md` dosyasındaki tabloları başlıklarına göre okur.
- `tokens.mjs`: `tokens/` klasöründeki JSON dosyalarından CSS değişkenleri üretir (açık ve koyu mod).

**Ne zaman dokunurum?** Normalde dokunmazsın.
