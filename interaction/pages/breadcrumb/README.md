# breadcrumb playground

**Bu klasör ne?** Figma'daki "↪︎ Breadcrumb" sayfasının code layer'ı. Çıktı: [layers/breadcrumb/index.html](../../layers/breadcrumb/index.html).

- `page.json`: kullanılan komponentler.
- `page.js`: sekmeler: Breadcrumb ve Breadcrumb Item. Collapsed'taki More düğmesi gizli sayfaları menüyle açar.

**Ne zaman dokunurum?** Komponente yeni bir property ya da varyant eklendiğinde.
