# cards playground

**Bu klasör ne?** Figma'daki "🗂 Cards" sayfasının code layer'ı. Çıktı: [layers/cards/index.html](../../layers/cards/index.html).

- `page.json`: kullanılan komponentler.
- `page.js`: sekmeler: Card, Card Header, Stat Card, Icon Stat, User Card. User Card ve Bulk Actions gerçek menü açar.

**Ne zaman dokunurum?** Komponente yeni bir property ya da varyant eklendiğinde.
