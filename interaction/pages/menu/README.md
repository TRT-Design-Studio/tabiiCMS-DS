# menu playground

**Bu klasör ne?** Figma'daki "📋 Menu" sayfasının code layer'ı. Çıktı: [layers/menu/index.html](../../layers/menu/index.html).

- `page.js`: sekmeler, kontroller ve menüyü bir düğmeden açan örnek.

**Ne zaman dokunurum?** Komponente yeni bir property ya da varyant eklendiğinde.
