# table playground

**Bu klasör ne?** Figma'daki "↪︎ Table" sayfasının code layer'ı. Çıktı: [layers/table/index.html](../../layers/table/index.html).

- `page.json`: kullanılan komponentler.
- `page.js`: sekmeler: Table Cell, Table Header Cell ve ikisini birlikte gösteren küçük tablo (seçim, sıralama).

**Ne zaman dokunurum?** Komponente yeni bir property ya da varyant eklendiğinde.
