# tabs playground

**Bu klasör ne?** Figma'daki "↪︎ Tabs" sayfasının code layer'ı. Çıktı: [layers/tabs/index.html](../../layers/tabs/index.html).

- `page.json`: kullanılan komponentler.
- `page.js`: sekmeler: Tabs (seçim gerçekten değişir, oklarla da), Tab Segment, Tab Underline.

**Ne zaman dokunurum?** Komponente yeni bir property ya da varyant eklendiğinde.
