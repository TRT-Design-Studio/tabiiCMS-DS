# tooltip playground

**Bu klasör ne?** Figma'daki "💬 Tooltip" sayfasının code layer'ı. Çıktı: [layers/tooltip/index.html](../../layers/tooltip/index.html).

**Ne zaman dokunurum?** Komponente yeni bir property ya da varyant eklendiğinde.
