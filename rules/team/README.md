# Ekip kuralları (team)

✅ **Herkes kural ekleyebilir.** PR ile gelir, ekipten biri onaylar.

## Nasıl yeni kural eklerim?

1. Yapay zekaya `basla: yeni kural, <konu>` yaz.
2. Kuralı ona anlat. Dosyayı [kural yazım formatına](../core/kural-yazim-formati.md) göre o oluşturur.
3. `oturumu bitir` → `gonder`

## Dikkat

- Buradaki bir kural [core](../core/README.md) kurallarıyla çelişemez. Çelişirse core kazanır.
- Core'daki bir kuralı değiştirmek istiyorsan buraya "onun tersi" bir kural yazma. [Öneri yaz](../../proposals/README.md).
- Kural `id`'leri `team.` ile başlar. Örnek: `team.badge-renk-kullanimi`
