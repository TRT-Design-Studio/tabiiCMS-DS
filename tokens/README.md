# Token'lar

🔒 **Korumalı klasör.** Elle düzenlenmez.

**Bu klasör ne?** Figma'daki değişkenlerin (renkler, boşluklar, yazı boyutları…) bilgisayarın okuyabileceği hali (JSON). Kodda kullanılan Tailwind teması bu dosyalardan **üretilir**. Böylece Figma'daki isim ile koddaki isim hep aynı kalır.

**Nereden gelir?** Figma'dan. Yapay zeka Figma'ya bağlanır, değişkenleri okur ve buraya yazar. Bir değeri değiştirmek istiyorsan **önce Figma'da değiştir.**

**Durum:** Henüz boş. Faz 1'de doldurulacak ([ROADMAP.md](../ROADMAP.md)).
